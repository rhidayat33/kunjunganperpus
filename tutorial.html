Dashboard Kunjungan

Tutorial Penggunaan

Panduan lengkap setup dan penggunaan Dashboard Kunjungan Perpustakaan PKN STAN.

⚙️ Bagian A — Setup Google Apps Script

1

Buka Google Apps Script

Buka browser dan kunjungi script.google.com. Login menggunakan akun Google Anda.

2

Buat Proyek Baru

Klik tombol + Proyek Baru (New Project) di bagian kiri atas. Beri nama proyek, misalnya: Kunjungan Perpustakaan PKN STAN.

3

Hapus Kode Default & Tempel Kode Baru

Hapus semua kode yang ada di editor, lalu tempel seluruh kode berikut ini:

// ============================================ // Google Apps Script — Kunjungan Perpustakaan // Dashboard Kunjungan PKN STAN // ============================================ var SPREADSHEET_ID = '1S2KQi9V0BM3RR_MMSfJ1Ua6KIgcH9APS2-fiQ_OH0_k'; var SHEET_GID = 620037545; function getSheet() { var ss = SpreadsheetApp.openById(SPREADSHEET_ID); var sheets = ss.getSheets(); for (var i = 0; i < sheets.length; i++) { if (sheets[i].getSheetId() === SHEET_GID) return sheets[i]; } return ss.getActiveSheet(); } function doPost(e) { try { var sheet = getSheet(); var timestamp = new Date(); var nama = (e.parameter.nama || '').trim(); var tujuan = (e.parameter.tujuan || '').trim(); var durasi = (e.parameter.durasi || '').trim(); sheet.appendRow([timestamp, '', nama, tujuan, durasi]); return jsonResponse({ status: 'success', message: 'Data berhasil disimpan.' }); } catch (err) { return jsonResponse({ status: 'error', message: err.toString() }); } } function doGet(e) { try { var sheet = getSheet(); var allRows = sheet.getDataRange().getValues(); var startIdx = 0; if (allRows.length > 0) { var firstCell = String(allRows[0][0]).toLowerCase(); if (firstCell === 'timestamp' || firstCell === 'waktu') startIdx = 1; } var result = []; for (var i = startIdx; i < allRows.length; i++) { var row = allRows[i]; var nama = String(row[2] || '').trim(); if (!nama) continue; var ts = ''; try { ts = (row[0] instanceof Date) ? row[0].toISOString() : new Date(row[0]).toISOString(); } catch(x){} result.push({ timestamp: ts, nama: nama, tujuan: String(row[3]||''), durasi: String(row[4]||'') }); } return jsonResponse({ status: 'success', total: result.length, data: result }); } catch (err) { return jsonResponse({ status: 'error', message: err.toString() }); } } function jsonResponse(obj) { return ContentService .createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
💾 Kode ini sudah tersimpan di file apps-script/Code.gs dalam folder proyek Anda.
4

Simpan Kode

Tekan Ctrl + S (atau klik ikon simpan) untuk menyimpan kode.

🚀 Bagian B — Deploy sebagai Web App

1

Klik "Deploy" → "New Deployment"

Di toolbar bagian atas editor Apps Script, klik tombol biru Deploy, lalu pilih New Deployment.

2

Pilih Tipe: Web App

Pada dialog yang muncul, klik ikon ⚙️ lalu pilih Web App sebagai tipe deployment.

3

Atur Izin Akses

Isi konfigurasi berikut:

  • Description: Kunjungan Perpustakaan PKN STAN (opsional)
  • Execute as: Me (akun Google Anda)
  • Who has access: Anyone — penting agar form bisa diakses tanpa login
⚠️ Jika memilih Anyone with Google Account, pengunjung harus login Google sebelum mengisi form. Pilih Anyone agar semua bisa mengakses.
4

Izinkan Akses (Authorize)

Klik Deploy. Jika diminta, klik Authorize access dan ikuti langkah login Google. Jika muncul peringatan "This app isn't verified", klik Advanced → Go to … (unsafe). Ini aman karena kode dibuat sendiri.

5

Salin URL Web App

Setelah berhasil deploy, akan muncul Web app URL. Salin URL tersebut — formatnya seperti:
https://script.google.com/macros/s/AKfy.../exec

📋 Simpan URL ini, Anda akan memerlukannya di langkah berikutnya.

🔗 Bagian C — Konfigurasi URL di Website

1

Buka Halaman Daftar Hadir

Buka file daftar-hadir.html di browser Anda.

2

Klik "Konfigurasi URL Apps Script"

Pada halaman Daftar Hadir, klik tombol kecil ⚙️ Konfigurasi URL Apps Script di bawah judul halaman.

3

Tempel URL & Simpan

Tempel URL Web App yang telah disalin ke dalam kotak input, lalu klik Simpan & Aktifkan. URL akan tersimpan di browser secara otomatis (localStorage).

4

Konfigurasi di Halaman Statistik

URL yang sama juga perlu dikonfigurasi di statistik.html. Lakukan hal yang sama: klik ⚙️ Konfigurasi URL, tempel URL, dan klik Hubungkan.

💡 URL disimpan per-browser (localStorage). Jika membuka di browser/komputer berbeda, perlu konfigurasi ulang.

📋 Bagian D — Menggunakan Form Daftar Hadir

1

Isi NIM / NIP / Nama

Pengunjung mengisi identitas sesuai status:

  • Mahasiswa: isi NIM (dimulai angka 3 atau 4, misal: 4101234567)
  • Pegawai: isi NIP (dimulai 19 atau 20, misal: 197001012000011001)
  • Tamu/Umum: isi nama lengkap
🔍 Sistem akan otomatis mendeteksi kategori pengunjung saat mengetik dan menampilkan badge konfirmasi.
2

Pilih Tujuan Berkunjung

Centang satu atau beberapa tujuan kunjungan dari 11 pilihan yang tersedia. Pilihan yang dipilih akan berubah warna biru sebagai konfirmasi.

3

Pilih Estimasi Durasi

Pilih salah satu dari empat kartu durasi: Kurang dari 1 Jam, 1–2 Jam, 2–3 Jam, atau Lebih dari 3 Jam.

4

Kirim Form

Klik tombol ✅ Kirim Daftar Hadir. Pesan sukses akan muncul jika data berhasil dikirim ke Google Sheets.

📊 Bagian E — Membaca Halaman Statistik

1

Stat Cards (Ringkasan)

Empat kartu di bagian atas menampilkan: Total Kunjungan keseluruhan, Kunjungan Hari Ini, Tujuan Terpopuler, dan Rata-rata Durasi kunjungan.

2

Tab Periode (Harian / Mingguan / Bulanan)

Gunakan tab di bawah stat cards untuk mengubah tampilan grafik Tren Kunjungan sesuai periode yang diinginkan.

3

Empat Grafik

  • Tren Frekuensi: bar chart jumlah kunjungan per periode
  • Kategori Pengunjung: donut chart Mahasiswa / Pegawai / Tamu
  • Durasi Kunjungan: bar chart distribusi lama kunjungan
  • Tujuan Berkunjung: horizontal bar chart frekuensi per tujuan
4

Perbarui Data

Klik tombol 🔄 Perbarui Data di pojok kanan atas untuk mengambil data terbaru dari Google Sheets tanpa me-reload halaman.

🔧 Troubleshooting

!

Form berhasil terkirim tapi data tidak muncul di Sheets

Pastikan URL Apps Script sudah benar. Coba buka URL langsung di browser — jika muncul JSON, berarti deployment berhasil. Jika muncul error, coba deploy ulang Apps Script.

!

Statistik tidak muncul / error "Gagal terhubung"

Pastikan URL Apps Script yang dikonfigurasi di halaman statistik sama persis dengan URL deployment. Coba klik 🔄 Perbarui Data. Jika masih gagal, periksa koneksi internet.

!

Setelah update kode Apps Script, data tidak berubah

Setiap kali mengubah kode Apps Script, Anda harus membuat deployment baru (bukan mengedit yang lama). Klik Deploy → New Deployment, lalu salin URL baru dan perbarui konfigurasi di website.

!

URL perlu dikonfigurasi ulang di browser lain

URL tersimpan di localStorage browser, bukan di server. Setiap browser/komputer baru perlu konfigurasi URL sekali saja.
